# Experiments v1 (Evidence-First)

This document describes the reproducible v1 experiment layer and hard-gate checks.

## Run Everything

```bash
python3 experiments/run_all.py
```

Artifacts are written to `results/`.

## Phase 2 Artifacts

- `results/invariant_residuals.csv`
- `results/overshoot_profiles.json`
- `results/energy_maps.npy`
- `results/invariant_convergence.png`

## Phase 2b Falsification Gates

Generated by `run_falsification_gates()`:

- `results/noise_robustness.json`
- `results/nonuniform_sampling.json`
- `results/baseline_comparison.json`
- `results/gates_report.json`

Gate intent:

1. Noise robustness checks bounded degradation for `step + gaussian noise` across multiple SNR values.
2. Nonuniform sampling checks drift from jittered-grid resampling against a uniform baseline.
3. Baseline comparison requires Gibbs detector to beat at least one baseline (TV or wavelet) on at least one key metric.

## Phase 3 Constrained Prototype

Generated by `run_constraint_prototype()`:

- `results/constrained_metrics.json`

Objective:

```text
L = reconstruction_error + lambda * invariant_residual^2
```

Toy tasks:

- 1D denoising
- truncated Fourier reconstruction
- edge-preserving smoothing

For each task, the report includes edge-zone and smooth-zone MSE and whether edge improvement was achieved without unacceptable smooth regression.

## Phase 4 Candidate Ranking

Generated by `rank_candidates()`:

- `results/candidate_rankings.csv`
- `results/candidate_ranking_report.json`
- `docs/industry/candidate_ranking_v1.md`

Selection is unblocked only when:

- `results/gates_report.json` has `all_pass = true`, and
- `results/constrained_metrics.json` has `pass = true`.
